# My To-Do List App

A simple Flutter To-Do List app with task statistics, feedback, and enhanced input.  
Manage your tasks efficiently with completion tracking and delete confirmation.

## 🚀 Features

- Add new tasks with validation (max 100 characters, no duplicates, not empty)
- Toggle tasks as complete/incomplete with Snackbar feedback
- Delete tasks with confirmation dialog and feedback
- Statistics card showing Total / Completed / Incomplete tasks
- Input enhancements: auto-capitalize, max length, Enter key adds task
- Responsive UI with ListTile decorations
